# Como adaptar o hook para o produto do usuário

## A ideia central

Um hook tem duas partes:

1. **Mecanismo**: o tipo de hook mais o gatilho (ex.: "Pare de" + identificação).
   Funciona para qualquer produto.
2. **Conteúdo**: o produto, a dor e as cenas específicas do vídeo original.
   Isso **não** se copia.

Adaptar é manter o mecanismo e trocar o conteúdo. Mudar o ângulo é manter o mecanismo e
trocar **a razão de compra** por trás do conteúdo.

## Mesmo ângulo

Use quando o produto do usuário resolve o mesmo tipo de problema ou desejo do vídeo original.

1. Pegue a fórmula do Passo 4.
2. Preencha as lacunas com a dor, o desejo e o vocabulário **do público do usuário**.
3. Recrie o visual com o que o usuário consegue gravar (celular, casa, produto na mão).
   Se o original usa algo caro (estúdio, ator, locação), proponha um equivalente barato que
   cause o mesmo efeito.
4. Mantenha o mesmo tempo: se a fala do original começa em 0,2s, a sua também.
5. Mantenha a ponte: o mesmo tipo de virada entre os 3 e os 6 segundos.

## Outro ângulo

Use quando o usuário quer testar outra razão de compra ou quando o ângulo original não se
encaixa no produto dele.

Escolha ângulos que o produto realmente sustenta:

| Ângulo | Pergunta que responde |
|---|---|
| Dor | O que dói hoje e para de doer? |
| Desejo / transformação | Como fica a vida depois? |
| Economia | Quanto dinheiro ou tempo poupa? |
| Praticidade | É mais fácil que a alternativa? |
| Medo / risco | O que acontece se não resolver? |
| Status / vaidade | Como a pessoa vai ser vista? |
| Prova / ceticismo | Funciona mesmo? (testes, números, reviews) |
| Inimigo comum | Contra o quê ou quem o produto está? (marca cara, indústria, método antigo) |
| Novidade | O que tem de novo que a pessoa nunca viu? |
| Presente | Para quem dar? |

Para cada ângulo novo:

1. Mantenha o **tipo de hook** e o **gatilho** do original.
2. Troque a promessa para o novo ângulo.
3. Ajuste o visual para mostrar o novo ângulo nos primeiros 1 a 2 segundos.

Exemplo, com a fórmula "Pare de [hábito] com [categoria] que [falha]":

- Dor: "Pare de esfregar a pia por 20 minutos com produto que não tira gordura."
- Economia: "Pare de gastar R$ 40 por mês com produto que acaba em uma semana."
- Inimigo comum: "Pare de pagar pela marca famosa num produto que é 90% água."

## Quando o usuário já tem um vídeo gravado

1. Rode o script no vídeo do usuário também.
2. Compare os dois raio-X camada por camada (visual, fala, texto, ritmo, ponte).
3. Diga o que mudar com o mínimo de regravação:
   - **Só editar**: cortar o começo morto, adiantar a melhor cena para o frame 1, adicionar
     texto na tela, efeito sonoro ou zoom.
   - **Regravar só o hook**: os 3 primeiros segundos, mantendo o resto.
   - **Regravar tudo**: só se o corpo não sustentar a promessa do hook novo.
4. Indique o segundo exato onde o novo hook se conecta ao vídeo existente.

## Cheque antes de entregar

- [ ] Dá para entender sem som?
- [ ] A primeira palavra ou movimento acontece em até 0,5s?
- [ ] O texto na tela se lê em 2 segundos?
- [ ] O corpo do vídeo entrega o que o hook promete?
- [ ] Nada foi copiado literalmente do original?
- [ ] A promessa é verdadeira e não deve ser reprovada pela plataforma?
